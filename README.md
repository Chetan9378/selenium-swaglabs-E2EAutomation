# Swag Labs End-to-End Automation

## Project Overview

This project automates the complete purchase flow of the Swag Labs application using Selenium WebDriver with Java.

The automation script validates the entire checkout process starting from login until successful order completion.

---

## Tech Stack

- Java
- Selenium WebDriver
- ChromeDriver
- Explicit Wait (WebDriverWait)
- ChromeOptions
- Eclipse IDE

---

## Test Scenario

The script performs the following steps:

1. Launch Chrome Browser
2. Open Swag Labs Website
3. Login using valid credentials
4. Add product to cart
5. Navigate to cart
6. Proceed to checkout
7. Enter customer information
8. Complete checkout
9. Verify successful order message
10. Download order PDF
11. Logout

---

## Concepts Used

- Selenium WebDriver
- Locator Strategies
- Explicit Wait
- ChromeOptions
- Dynamic Element Handling
- Assertions using Order Confirmation
- End-to-End UI Automation
